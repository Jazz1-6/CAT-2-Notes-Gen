# Example: DSA CAT-2 Notes

This example shows the skill applied to a Data Structures & Algorithms course, Modules 3 and 4.

## Inputs used

- **Subject**: DSA
- **Scope**: Module 3 (Trees & Graphs) + Module 4 (Searching & Sorting)
- **Exclusions**: Module 5 (MST, Prim's, Kruskal's, Dijkstra as standalone)
- **Code language**: C
- **Exam type**: Open book, 5 HOTs questions × 10 marks
- **Print target**: Even page count, ~36 pages
- **UI reference**: Java "CSE2006 Units 3&4 Study Guide" (structural inspiration)

## Outputs produced

- `output-notes.html` — full version with 26 HOT practice questions
- `output-notes-nohots.html` — same content, HOTs removed
- Rendered PDFs: ~36 pages each

## Key decisions

1. Module 5 excluded per user instruction
2. HOT questions weighted by exam likelihood (Trace > Comparison > Design)
3. Tie-break rules documented in a dedicated table
4. Every algorithm has an accompanying "What if…?" sensitivity note

## Files in this folder

- `input-scope.md` — the syllabus/scope the notes were generated from
- `output-notes.html` — the full notes (open in a browser)
- `output-notes-nohots.html` — the no-HOTs version
